================================================================================
Stage 1.3-HIL GC9A01 (240x240 Circular IPS) Display Layout & Text Specification
================================================================================
Hardware: 1.28-inch Round LCD (GC9A01), SPI1 Shared Bus, 240x240 Resolution
Color Depth: RGB565 (16-bit)

--------------------------------------------------------------------------------
1. Boot Splash Screen (AppTFT_Test)
--------------------------------------------------------------------------------
Visual Duration: 1000 ms
Background: BLACK (0x0000)
Boundary: Circle centered at (120, 120), radius 113 px, DARKBLUE (0x0010)

ASCII Screen Map (Circular Screen Projection):
                 .---------------------.
              .-'                       '-.
            .'          SPI1 LAB           '.       <-- (68, 34) CYAN 24pt
           /                                 \
          |            STM32F103C8            |     <-- (60, 84) WHITE 16pt
         |            GC9A01 W25Q128           |    <-- (52, 109) LGRAY 16pt
         |             DMA + FLASH             |    <-- (70, 136) WHITE 16pt
         |                                     |
         |         [RED] [GREEN] [BLUE]        |    <-- (75..165, 166..173) RGB Bars
          |             SELF TEST             |     <-- (80, 187) GREEN 16pt
           \                                 /
            '.                             .'
              '-.                       .-'
                 '---------------------'

Element Details:
- Title: "SPI1 LAB" at (68, 34), Color: CYAN (0x7FFF), Font: 24pt
- Target MCU: "STM32F103C8" at (60, 84), Color: WHITE (0xFFFF), Font: 16pt
- Peripherals: "GC9A01 W25Q128" at (52, 109), Color: LGRAY (0xC618), Font: 16pt
- Bus Features: "DMA + FLASH" at (70, 136), Color: WHITE (0xFFFF), Font: 16pt
- RGB Color Verification Bar:
  * RED block: (75, 166) to (105, 173) [30x8 px]
  * GREEN block: (105, 166) to (135, 173) [30x8 px]
  * BLUE block: (135, 166) to (165, 173) [30x8 px]
- Status: "SELF TEST" at (80, 187), Color: GREEN (0x07E0), Font: 16pt

ASCII Screen Map:
                 .---------------------.
              .-'                       '-.

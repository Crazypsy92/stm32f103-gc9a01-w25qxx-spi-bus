[Root Cause Analysis of Initial "花屏" (Blurred/Garbled Display)]
1. Pin Mapping Mismatch:
   - When the user moved the physical jumper wire of TFT DC from PB13 to PA4 (to prepare for Dual SPI where PB13 is used by SPI2_SCK), firmware built with SHARED_SPI1 (which drove PB13) left PA4 floating.
   - Without a valid DC signal driving PA4, GC9A01 could not distinguish command bytes (0x2A Column Address, 0x2B Row Address, 0x2C Memory Write) from pixel stream data.
   - The display controller treated command coordinates as pixel data and pixel data as configuration registers, corrupting internal registers and producing garbled pixels ("花屏").
2. Verification of Fix:
   - Rebuilding firmware with CONFIG_DUAL_SPI=1 correctly associates GC9A01 DC control with PA4 (LL_GPIO_PIN_4).
   - Upon running TFT_ONLY on PA4, the screen displays crystal clear solid colors without any artifacts or flickering.
